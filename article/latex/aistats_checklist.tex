\section*{Checklist}

\begin{enumerate}

  \item For all models and algorithms presented, check if you include:
  \begin{enumerate}
    \item A clear description of the mathematical setting, assumptions, algorithm, and/or model. [Yes] Section~\ref{sec:method} describes MoSAIC; Appendices~\ref{app:lru}--\ref{app:rl} specify the extensions and pilot protocols.
    \item An analysis of the properties and complexity (time, space, sample size) of any algorithm. [Yes] Section~\ref{sec:method} gives parameter, carried-state, and per-token routing complexity; no sample-complexity theorem is claimed.
    \item (Optional) Anonymized source code, with specification of all dependencies, including external libraries. [Yes] The supplementary archive contains the 1M Text8 models, configuration, runner, dependencies, and instructions.
  \end{enumerate}

  \item For any theoretical claim, check if you include:
  \begin{enumerate}
    \item Statements of the full set of assumptions of all theoretical results. [Yes] Section~\ref{sec:bayesian} states Assumption G; Appendix~\ref{app:bayesian} specifies each result's additional conditions.
    \item Complete proofs of all theoretical results. [Yes] Appendix~\ref{app:bayesian} contains complete proofs of five theorems, four lemmas, and Proposition~\ref{prop:column-count}.
    \item Clear explanations of any assumptions. [Yes] Appendix~\ref{app:bayesian} explains the assumptions and their limits for learned routing and BPC.
  \end{enumerate}

  \item For all figures and tables that present empirical results, check if you include:
  \begin{enumerate}
    \item The code, data, and instructions needed to reproduce the main experimental results (either in the supplemental material or as a URL). [No] Supplementary code covers the 1M Text8 comparison, but not every pilot or exact replay of 10M runs with unavailable seeds.
    \item All the training details (e.g., data splits, hyperparameters, how they were chosen). [No] Sections~\ref{sec:method}--\ref{sec:experiments} and Appendices~\ref{app:protocol}--\ref{app:rl} specify protocols and 1M seeds. The 10M seeds and complete tuning records are unavailable.
    \item A clear definition of the specific measure or statistics and error bars (e.g., with respect to the random seed after running experiments multiple times). [Yes] Section~\ref{sec:experiments}, captions, and Appendix~\ref{app:uncertainty} define metrics, budgets, launch counts, and sample SD. Pilot checkpoints are not independent replicates.
    \item A description of the computing infrastructure used. (e.g., type of GPUs, internal cluster, or cloud provider). [Yes] Sections~\ref{sec:resources} and~\ref{sec:limitations} describe the hardware. Appendix~\ref{app:resources} reports costs for the 48 confirmed H100 runs at the larger scale.
  \end{enumerate}

  \item If you are using existing assets (e.g., code, data, models) or curating/releasing new assets, check if you include:
  \begin{enumerate}
    \item Citations of the creator If your work uses existing assets. [Yes] We cite text8, Zoology/MQAR, POPGym, and the original model and technique papers.
    \item The license information of the assets, if applicable. [No] A complete license inventory for the data and implementation dependencies has not been provided.
    \item New assets either in the supplemental material or as a URL, if applicable. [Yes] An anonymous supplementary code archive is supplied.
    \item Information about consent from data providers/curators. [Not Applicable] We use an existing public text corpus and an algorithmic generator, without collecting new human data.
    \item Discussion of sensible content if applicable, e.g., personally identifiable information or offensive content. [No] A separate sensitive-content audit of text8 was not conducted.
  \end{enumerate}

  \item If you used crowdsourcing or conducted research with human subjects, check if you include:
  \begin{enumerate}
    \item The full text of instructions given to participants and screenshots. [Not Applicable] No human participants.
    \item Descriptions of potential participant risks, with links to Institutional Review Board (IRB) approvals if applicable. [Not Applicable] No human participants.
    \item The estimated hourly wage paid to participants and the total amount spent on participant compensation. [Not Applicable] No human participants.
  \end{enumerate}

\end{enumerate}
