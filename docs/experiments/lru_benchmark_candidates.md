# Benchmark candidates for the column LRU model

Reviewed on 2026-10-02. The [provisional Aliased Cubes experiment](aliased_cubes.md) and [MQAR experiment](mqar.md) have been added to the code; the other entries are recommendations for future experiments. Priority reflects suitability for the present architecture and availability of external comparisons, not expected gains.

## Recommended first set

| Benchmark | Architectural question | Useful external comparisons | Adaptation and priority |
| --- | --- | --- | --- |
| **POPGym** | Can persistent columns improve memory-dependent decisions at low compute cost? | The official suite provides 13 memory model implementations, including GRU/LSTM, linear attention, fast weights, LMU, diagonal SSM and DNC. | Highest RL priority: extend the existing POPGym integration with RepeatPrevious, CountRecall, Concentration and navigation tasks at fixed difficulties; share the same observation adapter and PPO settings. |
| **Long Range Arena** | Does the lightweight recurrence retain information needed for long-sequence classification? | Efficient Transformer results plus the original LRU paper's LRA results and the broader SSM literature. | Highest supervised priority: start with ListOps and Pathfinder, then text classification; use a shared readout of column 0 and match preprocessing, causal/bidirectional settings and pooling. |
| **Zoology / MQAR** | How does associative recall capacity change with the number of stored pairs and distraction length? | Public architecture implementations and comparison experiments for Mamba/Mamba2, Hyena, RetNet, GLA, Based and other efficient sequence models. | Highest cheap diagnostic priority: token embeddings and an answer head, loss only on query targets; vary sequence length and key/value pairs independently. |

POPGym's source and model list are available in the [official repository](https://github.com/proroklab/popgym). The original suite includes a common memory-model harness; its published results do not become directly comparable merely by using the same task names. Since Knitwork already has a POPGym runner, environment/wrapper semantics and the learning algorithm need checking before adding the new models to that comparison.

LRA's tasks and data instructions are in the [official repository](https://github.com/google-research/long-range-arena); the direct relevance to the present cells comes from [Orvieto et al., ICML 2023](https://proceedings.mlr.press/v202/orvieto23a.html). A column GridRNN with residual feedback is a different architecture from the original stacked LRU, so its published scores are reference points rather than an expected result. Start with manageable lengths; Path-X is a later stress test, not the first pilot. Sequential execution and the current feedback loop also mean one cannot assume the original LRU's parallel-training efficiency transfers to this model.

The [official Zoology repository](https://github.com/HazyResearch/zoology) includes reproducible synthetic recall experiments and model implementations. MQAR is related to SDQ but adds an externally used benchmark and a controlled capacity/length sweep. It is still a synthetic diagnostic; use it alongside a realistic or structured task, rather than as the sole evaluation of useful memory. Match the original generator, vocabulary, pair distribution and query masks when comparing published curves.

## More substantial follow-ups

| Benchmark | Why it is interesting | Available comparisons | Cost / comparison caveat |
| --- | --- | --- | --- |
| **Memory Gym: Mortar Mayhem, Mystery Path, endless variants** | Test remembering an ordered instruction sequence, a revealed path, and memory limits as episodes grow. | Official recurrent PPO and Transformer-XL PPO implementations; published GRU/TrXL comparisons. | Moderate RL work: common visual encoder and actor/value heads; finite and endless results must be kept separate. |
| **Crafter / Craftax** | A richer task with exploration, resource management and delayed achievements beyond pure memory tests. | Crafter has a 1M-step scoreboard including PPO, Dreamer and recurrent/attention agents; Craftax has separate 1M/1B scoreboards and recurrent PPO/GTrXL/PQN entries. | Higher cost: common encoder and RL algorithm; the scoreboard compares whole agents, so isolate the core swap with a rerun recurrent baseline. |
| **Memory Maze** | Test spatial memory and internal map information over long visual trajectories. | Official IMPALA/Dreamer baselines plus an offline dataset and representation probing baselines. | Highest-cost option here for online RL; an offline representation experiment is an easier start, with ground-truth labels confined to the declared probe/evaluation. |

Memory Gym's [official environment repository](https://github.com/MarcoMeter/endless-memory-gym) links the recurrent PPO and Transformer-XL baselines, and the [authors' experiment page](https://marcometer.github.io/jmlr_2024.github.io/) documents comparisons. Endless Mortar Mayhem is especially informative for a fixed-size recurrent state: success can be plotted against instruction count, making memory limits easier to interpret than a single average return. Mystery Path is closer to the aliased-navigation question. Proposed architecture-specific advantages remain hypotheses.

[Crafter](https://github.com/danijar/crafter) has an explicit 1M-interaction comparison protocol, 22 achievement success rates and a geometric-mean score. It offers a broad public comparison base, but its performance depends on exploration and perception as well as recurrent memory. [Craftax](https://github.com/MichaelTMatthews/Craftax) supplies separate budget tables, standard recurrent baselines and a small offline dataset of mixed-skill human trajectories. The official README recommends an older environment version for that dataset, so imitation learning requires checking/version-pinning dataset compatibility; it is not automatically comparable to online-RL leaderboard scores. Crafter, Craftax-Classic and full Craftax are different benchmarks and should have separate result tables.

[Memory Maze](https://github.com/jurgisp/memory-maze) explicitly provides online RL baselines and an offline dataset for representation learning. This is a strong spatial-memory test, but its public comparison pool is narrower than LRA/POPGym and its online compute demands are greater. It is a follow-up after demonstrating stable learning on smaller memory tasks.

## Suggested experiment order and reporting

My recommended first comparison set is **MQAR + LRA subset + POPGym subset**, alongside the prepared Aliased Cubes diagnostic. These distinguish associative capacity, long-sequence reasoning and memory-dependent control with reasonably accessible comparison code. For a more application-facing result, add **Crafter or Craftax-Classic** afterward; for a focused spatial-memory result, choose **Mystery Path** before the heavier Memory Maze.

Use the current L2C4/H180 baseline first and evaluate sparse variants only after it learns reliably. For each new task, rerun at least a GRU/LSTM-style recurrent control and a strong relevant efficient model using the same data, encoder, optimizer or RL algorithm, split, interaction budget and seeds. Published scores give context; matched local baselines determine the architecture comparison. Report parameter count, required/allocated state, throughput and peak memory separately. A fixed state dimension is a capacity comparison, not a substitute for actual resource measurements.

For all suites, keep environment versions, observation wrappers, data splits, sequence lengths, test-time state resets, training exposure and any external demonstrations explicit. In RL, adding imitation data, a world model or an exploration bonus changes the whole-agent comparison and should not be attributed solely to the LRU columns. Readout remains through column 0; no semantic roles are assigned to peripheral columns in these proposed tests.
